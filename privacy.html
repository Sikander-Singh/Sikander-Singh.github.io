Privacy Policy

The Ugg Files upload and analytics tool. Last updated: 17 October 2026.

This is a personal tool used only by the owner of the YouTube channel "The Ugg Files". It is not a public service and has no other users.

What the tool does

With the channel owner's permission (Google sign-in), the tool uploads videos, thumbnails, captions and playlists to the owner's own YouTube channel, and reads that channel's own analytics such as views and watch time.

Data

The tool does not collect data about visitors or viewers. Channel data it reads stays on the owner's own computer. It is not sold, shared with third parties, or used for advertising. Sign-in tokens are stored only on the owner's computer.

Google user data

The tool's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The owner can revoke access at any time at myaccount.google.com/permissions.

Changes

If this policy changes, the new version will appear on this page.
